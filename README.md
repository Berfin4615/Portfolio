# 🎨 Berfin's Portfolio

Welcome to my interactive, animated, and responsive developer portfolio!  
Built with **Vite + React + TypeScript + Tailwind CSS + Framer Motion**, this site showcases my projects, experiences, and a contact form.

---

## 🌐 Live Preview

> [https://berfin4615.github.io/Portfolio/]([https://berfin4615.github.io/Portfolio/])

---

## 🚀 Tech Stack

- **React** + **Vite**
- **TypeScript**
- **Tailwind CSS**
- **Framer Motion**
- **Formspree** (Contact Form)
- **GitHub Pages** (Deployment)

---

## 📁 Folder Structure

```
public/                 # Static assets like images and textures
src/
├── components/         # Reusable UI components
├── pages/              # Main sections: Home, Projects, Experiences, Contact
├── styles/             # Tailwind + noise background styles
├── App.tsx             # Main app component
└── main.tsx            # Entry point
```

---

## 📦 Installation

```bash
git clone https://github.com/Berfin4615/portfolio.git
cd portfolio
npm install
npm run dev
```

---

## 📤 Deployment

This site is deployed on **GitHub Pages** using the `gh-pages` branch.

To build and deploy:

```bash
npm run build
npm run deploy
```

Make sure your `vite.config.ts` includes:

```ts
base: "/Portfolio/"
```
